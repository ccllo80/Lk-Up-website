# Lk Up

موقع بسيط لرفع الصور ومقاطع الفيديو وملفات GIF ومشاركتها بروابط مباشرة وصفحات عرض وتضمين.

## المتطلبات

- Node.js 20 أو أحدث
- مشروع Supabase

## التشغيل محلياً

```bash
npm install
cp .env.example .env
npm run dev
```

أضف بيانات مشروع Supabase إلى ملف `.env`:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY` (مفتاح anon / publishable فقط، لا تضع service_role في الواجهة)
- `VITE_SUPABASE_BUCKET` (اختياري، الافتراضي `lk-up-media`)

## إعداد التخزين

1. افتح SQL Editor في مشروع Supabase.
2. نفّذ محتوى الملف `supabase/schema.sql`.
3. أعد تشغيل الموقع.

## الميزات الحالية

- رفع الصور JPEG وPNG وWebP وGIF، والفيديو MP4 وWebM.
- الحد الأقصى 30 ميغابايت لكل ملف.
- اختيار الملف من الجهاز أو السحب والإفلات.
- فحص توقيع الملف في المتصفح قبل الرفع، إضافة إلى قيود الحجم وMIME في Storage.
- روابط صفحة العرض، والرابط المباشر، ورابط الوسيط، وصفحة التضمين، وكود HTML.
- واجهة متجاوبة مع الهاتف والكمبيوتر.

## ملاحظات أمنية مهمة

- الرفع مجهول ومتاح للعامة؛ لا توجد مصادقة أو حصص مستخدمين أو آلية حذف في النسخة الأولى.
- روابط الملفات عامة، وأي شخص يمتلك الرابط يستطيع مشاهدة الملف.
- فحص التوقيع في المتصفح وقيود MIME والحجم في Supabase تقلل الملفات غير المناسبة، لكنها ليست فحصاً أمنياً كاملاً لمحتوى الملفات. للإطلاق العام واسع النطاق، أضف Edge Function للتحقق من التوقيع على الخادم، ومحدد معدل رفع، وحماية من الإساءة، وسياسة احتفاظ/حذف.
- لا تضع أبداً مفتاح `service_role` أو أي سرّ خاص في متغير يبدأ بـ `VITE_`.
